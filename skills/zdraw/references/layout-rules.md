# zdraw · 布局语法(权威)

本文是 zdraw 布局语法的**唯一权威**——连线、节点盒、网格、预算、尺寸预设全在这。颜色/字体走 `brand-mapping.md` 语义角色;本文只管**布局**。坐标计算优先用 `scripts/zdraw_layout.py`(hierarchy/sequence/grid 三算法自动落实本文硬规则),脚本覆盖不了的自由摆件手写守规。

## 常用 8 类型速查

| 类型 | 布局语法一句话 |
|---|---|
| 架构图 architecture | 分层/分区(zone)摆放,节点盒 + 正交箭头,箭头先画节点后画 |
| 流程图 flowchart | 顶部向下主干,分支侧摆,决策菱形,每条边有标签 |
| 时序图 sequence | 垂直生命线(≤5 条),水平消息箭头,激活条可选 |
| ER 图 er | 实体盒(名 + 字段表),关系线两端标基数(1-N) |
| 状态机 state | 圆角状态盒 + 迁移箭头,箭头标 `事件[守卫]/动作` |
| 泳道 swimlane | 水平泳道(≤5),步骤盒在道内,跨道箭头表交接 |
| 树 tree | 根在上,子节点扇形下摆,深度 ≤4 |
| 层栈 layer stack | 水平条带自上而下堆叠,每层一个标签盒 |

## 硬规则

### 连线

1. **正交圆角连线强制**:不同 x/y 轴的节点之间禁止对角斜线;每个拐角是 r=8 的四分之一圆弧。同轴(共享 x 或 y)才允许直 `<line>`。肘线路径:`M x1,y1 → H/L 到拐点前 r 处 → Q 控制点 → 继续`,或用 `path` 的 `A` 弧。
2. **标签必须带遮罩 + 间隙**:每个箭头标签背后有不透明 `paper` 色 rect;遮罩底边与连线之间**留 6–10px 可见间隙**——连线必须看得见。标签 ≤14 字符、全大写、居中于线段中点。垂直线段的标签放侧面,同样留隙。禁止 `writing-mode: vertical`。
3. **无重叠连线**:两条连线不得共享路径、并行叠放或互相压线。不可避免交叉时用**桥/跳线**(crossing 处小半圆弧)。平行同向连线全程间距 ≥12px。
4. **同边多附着点扇形展开**:同一盒边的 N 条连线各自有独立附着点,相邻间距 ≥12px(极小盒 8px);第 k 个附着点在边长 L 上位于 `L * k / (N+1)`。
5. **连线不穿无关节点**:默认绕行。唯一例外——中间节点几何上不可避免地挡在唯一直达路径上:线必须虚线(`stroke-dasharray="4,3"`)示"过境非交互",标签放在可见端,箭头只落在真终点。
6. **箭头先画、节点后画**(z-order 让线压在盒下);箭头 marker 三件套常备:`arrow`(muted)/ `arrow-accent` / `arrow-link`,虚线 = 可选/异步/返回。

### 节点盒

```
1. 不透明 paper 底 rect(防箭头透色)
2. 样式 rect(rx=6,fill+stroke)
3. 类型标签(rx=2 小矩形,mono 7-8px 大写)
4. 节点名(sans 12px 600,居中)
5. 技术子标签(mono 9px:muted)
```

节点填充语义:focal ≤2 个用 `accent-tint`+`accent` 描边;普通节点白底 `ink` 描边;存储/状态 `ink @ 0.05`;外部/云 `ink @ 0.03` + `ink @ 0.30` 描边;可选/异步 `ink @ 0.02` + 虚线。

### 布局与预算

- **4px 网格**:字号/坐标/尺寸/间距全部被 4 整除(字号 8/12/16/20/24;间距 20/24/32/40/48;盒宽 80–240 档;圆角 4/6/8;内边距 8/12/16)。坐标末位是 1/2/3/5/6/7/9 → 改。
- **复杂度预算**:≤9 节点、≤12 箭头;超了拆 overview + detail 两张,不硬塞。
- **图例**:水平条带放图底部(发丝线分隔),绝不浮在图内;viewBox 高度相应 +60px。
- **去冗余**:两节点永远同行 → 合一;关系能从布局看出来 → 删线;永远问"还能删掉什么"。

### SVG a11y

- `<svg role="img" aria-labelledby="<slug>-title <slug>-desc">`;`<title>` 是 svg 第一个子元素(在 `<defs>` 前);ID 带图 slug 前缀,禁止裸 `title`/`desc`。
- `<title>` ≤60 字符主题名;`<desc>` 一句话说清图展示什么(讲内容,不描述几何形状)。
- 装饰性 SVG 用 `aria-hidden="true"`。

## 导出

- **SVG**:提取 `<svg>` 节点(去掉 editorial 包装)存为 `.svg`。
- **PNG**:无头浏览器截图该 `<svg>` 的 bounding box,按 `viewBox × 缩放因子` 定尺寸(如 slide-16x9 → 1920×1080)。
- 导出是**手动动作**——用户没要求不主动产出导出文件。

## 尺寸预设

| 预设 | 用途 | viewBox |
|---|---|---|
| `doc-inline` | 文档/README 内联 | 800×600 上下 |
| `doc-wide` | 文档通栏 | 1120×(按内容) |
| `slide-16x9` | 幻灯片/封面 | 1600×900 |
| `social-og` | 社交分享卡 | 1200×630 |
| `fit` | 设计稿内嵌 | 按容器适配 |

尺寸预设同时约束**字号阶梯**:slide 用 16px 节点名而不是 12px——只缩画布不缩字是投影不可读的头号原因。
