# 质量门禁 — zasset 三测细则 + SVG 工程质量 + mini brand guide 模板

> 交付前逐项自检。**未全过 → 回炉**,logo/图标类尤其不许带病交付。

## 一、三测(核心门禁)

### 1. 缩放测试
- 把主图形缩到 **16×16** 看轮廓:主体一眼可辨识(拟人化联想允许,细节不可辨识允许)
- 再缩到 **32×32**:线条不得糊成一团;描边宽度按缩放档位有意识取舍
- 方法:浏览器开母版,devtools 里强设 `width:16px` 或做对比页;截图放大肉眼复核

### 2. 单色测试
- 全图转纯黑(`fill:#000`):形态完整、负空间关系不丢
- 全图转纯白:同上
- 不依赖颜色区分的图形才合格——靠色差撑结构的 logo 在单色场景会废

### 3. 对比度测试
- 文字元素与其底色:**AA(≥ 4.5:1)**,大字标 ≥ 3:1 可接受但需在 brand guide 声明最小字号场景
- 图形与底色 3:1 起(WCAG 非文本元素标准)
- 深浅两种主题下各测一遍

## 二、SVG 工程质量

| 检查 | 标准 |
|---|---|
| viewBox | 显式声明且比例正确;禁止靠 width/height 硬拉伸 |
| id 唯一 | 同页可能内联多份 SVG,id 前缀隔离(`<slug>-`) |
| 无位图 | `<image>`/base64 位图嵌入 = 直接打回 |
| path 卫生 | 合并可合并路径、去重复节点、坐标小数 ≤ 2 位 |
| 体积 | 零视觉损失前提下精简;一般单文件 < 512KB,超限先查冗余再谈豁免 |
| 可访问性 | 含语义时补 `<title>` + `aria-labelledby`(装饰性 SVG 置 `aria-hidden="true"`) |

## 三、mini brand guide 模板(logo 场景交付必备)

落盘 `design/assets/<slug>/BRAND.md`:

```markdown
# <品牌名> Visual Quick Guide

## 主标识
![logo](./<slug>.svg)

| 变体 | 文件 | 使用场景 |
|---|---|---|

## 色值
| Token | HEX | RGB | 用途 |

## 字体
| 用途 | 字体 | 授权状态 |

## 最小使用尺寸 / 安全区
- 图形标 ≥ __px;组合标 ≥ __px 宽
- 安全区 = 图形高度 __ 倍范围内无其他元素

## 禁用示例
- ❌ 拉伸变形 / ❌ 加投影描边 / ❌ 改配色至低对比底 / ❌ 复杂背景直压正片

## 印刷注意(如有印刷场景)
SVG 为 RGB;四色印刷需转 CMYK 并校样,黑字建议单黑(K100)避免套印偏色。
```

## 四、暗色模式专项(web 场景)

- README 引用范式:
  ```html
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="./<slug>-dark.svg">
    <img src="./<slug>.svg" alt="<品牌名> logo">
  </picture>
  ```
- `-dark.svg` 不是简单反色:按品牌深色 token 重排层次,accent 保持可辨识

## 五、回炉判定速查

| 症状 | 动作 |
|---|---|
| 16px 认不出主体 | 回精修:加粗主线、删细节、提对比 |
| 单色后散架 | 回造型:结构改靠形不靠色 |
| 渐变救不了的"AI 感" | 回探索:几何骨架推倒重来 |
| 体积爆表 | 先合并/去重/降精度,再评估是否该减细节 |
