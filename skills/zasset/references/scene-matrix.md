# 场景矩阵 — zasset 各场景精确规格

> 单位均为 px。所有导出从 SVG 母版生成,不手改位图。

## 1. 品牌标识(logo)

### 变体矩阵(全出,缺一不交付)

| 变体 | 文件命名 | 用途 |
|---|---|---|
| 正片 | `<slug>.svg` | 默认浅底场景 |
| 反白 | `<slug>-white.svg` | 深底/品牌色底 |
| 纯黑 | `<slug>-black.svg` | 单色印刷/传真/水印 |
| 纯白 | `<slug>-mono-white.svg` | 压深色照片 |
| 暗色模式 | `<slug>-dark.svg` | `prefers-color-scheme: dark` 自动切换(GitHub README 场景) |

暗色模式实现:同形不同填充,README 引用 `<picture>` + `media` 切换源文件。

### 尺寸导出

| 导出 | 尺寸 |
|---|---|
| PNG 標准 | 512 / 256 / 128 / 64 / 32 |
| favicon | 见图标系统 |
| app 图标 | 见图标系统 |

### 硬规则
- 最小使用尺寸在 mini brand guide 里显式声明(图形标一般 ≥ 24px)
- 组合标必须有「图形可拆出单独用」的判断:横排空间不足时用图形标

## 2. 图标系统

### favicon 组
| 文件 | 规格 |
|---|---|
| `favicon.svg` | 矢量母版(modern 浏览器直读) |
| `favicon.ico` | 多尺寸打包 16+32+48 |
| `apple-touch-icon.png` | 180×180(圆角由系统处理,别预切) |
| `icon-192.png` / `icon-512.png` | PWA manifest |

### app 图标(iOS/Android 交付形态)
- iOS:`1024×1024` 无透明单张(App Store 由工具链派生全部档位)
- Android:自适应图标交前景层 + 背景层两张 `108×108dp`(安全区居中 66dp 内),或简化交 `512×512` 商店图
- 预览合成图一张,模拟主屏圆角遮罩效果给用户确认

### 界面图标组(线性或面性一套)
- 24×24 画板、2px 描边起稿;栅格:居中 20×20 安全区
- 一套内风格唯一:要么全线性要么全面性,圆角半径一致
- 导出:SVG 单文件 + 合并 sprite(svg symbol)两形态

## 3. 社媒传播(固定画幅)

| 场景 | 画幅 | 备注 |
|---|---|---|
| OG 分享图 | **1200×630** | 文字安全区:边缘各留 ≥ 60px;正文区文字 ≥ 32px |
| GitHub README banner | 1280×640 | 深浅双版(repo 可能两种主题) |
| 公众号封面 | 900×383(次条 200×200) | 关键信息避开右侧比例缩略裁切区 |
| Twitter/X 头图 | 1500×500 | 中央 1200×500 为常规可视区 |
| launch/产品发布图 | 1600×900 | Product Hunt 等通用横幅 |

导出固定画幅类一律 PNG @2x(即按 2 倍尺寸截图导出)+ SVG 源稿留存。

## 4. 插画资产

| 场景 | 要求 |
|---|---|
| 空状态 | 至少深浅底两版;重心居上 1/3,下方留文案位置 |
| 404/500 | 配合页面文案的情绪方向先确认再画 |
| onboarding 引导图 | 同一风格成套;角色比例跨图一致 |
| hero spot 插画 | 与品牌 accent 色呼应但克制(< 30% 面积) |

插画统一走「几何构成 + 品牌色」路线,不追求拟物细节——保持 SVG 可维护与体积可控。

## 5. 物料延展

| 场景 | 规格 |
|---|---|
| 海报 | A 系比例优先(A4 2480×3508 @300dpi 导出)、数字海报 1242×1660 |
| badge | shields.io 兼容自查:静态 svg 宽高比贴合徽章惯例 |
| 名片样式 | 90×54mm(3.543×2.126in)@300dpi,出血 3mm |

印刷类交付必须在 brand guide 标注色彩模式注意事项(SVG 是 RGB;真印刷需 CMYK 转档说明)。

---

### 通用导出纪律
1. 每个场景目录一份 `MANIFEST.md`(或沿用 SKILL.md 输出格式中的表格):文件 → 用途 → 尺寸
2. 文件名只含小写字母/数字/连字符
3. 探索废稿进 `explore/`,正式交付目录里不许有未选中的备选稿
